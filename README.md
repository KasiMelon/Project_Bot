Мы планируем создать бота прогноза погоды.
Основные функции бота:
1. Прогноз погоды на день, выбранный пользователем
2. Вывести прогноз на ближайшую неделю
3. Добавить кнопку быстрого прогноза (на текущий день в ближайшие часы с максимально краткой и информативной информацией
4. Возможность выбора локации (города) показа погоды
5. Всплывающее уведомление

Команды:
/stats - Осадки, температура и погодные условия в целом на момент запроса
/forecast - Показ погоды на запрошенный день недели (предел - 1 неделя вперёд)
/help - показ существующих команд и их краткое описание, команды будут дополняться в дальнейшем

План:
1. Запрос от пользователя через сканнер и ответы на сообщения, проработать исключения и тд и тп (dev)
2. API яндекс погоды, подвязка к дате
3. Разобраться с выводом
4. Индивидуальные фичи
5. Разобраться со стандартизированной структурой проекта
