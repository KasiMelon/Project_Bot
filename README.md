Цель проекта: Создать Telegram-бота прогноза погоды

Основные функции:
1) Текущая сводка(stats) - мгновенное получение краткой и максимально информативной сводки погодных условий на текущий момент
2) Гибкий прогноз(forecast) - получение прогноза погоды на выбранное количество дней( от 1 до 3 дней вперёд )
3) Умная геолокация - встроенная кнопка для автоматического определения погоды по координатам пользователя
4) Многошаговый интерфейс - удобный выбор параметров

Команды бота:
1) /stats [город] — Краткая сводка: осадки, температура и погодные условия на момент запроса
2) /forecast [город] [кол-во дней] — Детализированный прогноз погоды на запрошенное количество дней (до 3 дней)
3) /start — Запуск бота и вывод главного меню
4) /help — Справочник по существующим командам и их описание
5) /exit — Завершение сеанса/отмена текущего действия

Технический отчёт:
1) Трёхуровневая модель:
   Проект разделен на логические слои. У нас есть DTO (WeatherDTO) для хранения данных, сервисный слой (WeatherService, GetWeatherWithApi) для бизнес-логики и связи с API, и контроллеры (TelegramBot, BotController, KeyboardFactory) для обработки команд и UI.
2) Работа с API:
   Реализовали класс GetWeatherWithApi, который формирует HTTP-запросы. В WeatherService написали парсеры JSON-ответов сервера. Внедрили обработку ошибок (HTTP 400, 401, 404), чтобы бот не падал, а сообщал пользователю о неверном городе или проблемах с сетью.
3) Динамический интерфейс
   Всю работу с кнопками вынесли в фабрику KeyboardFactory. Реализовали динамическую подмену клавиатур: главное меню, меню выбора цифр (1-3 дня) и меню быстрых городов. Клавиатура меняется в зависимости от того, в каком "состоянии" находится пользователь.
